# Распознавание рукописных символов EMNIST

## 1. Описание решения

Проект решает задачу многоклассовой классификации рукописных символов.

В качестве данных используется датасет **EMNIST Balanced**, содержащий изображения рукописных цифр и латинских букв размером `28 × 28` пикселей.

Всего модель распознаёт **47 классов**:

- цифры `0–9`;
- заглавные латинские буквы;
- часть строчных латинских букв.

Для обучения данные были разделены на:

- обучающую выборку;
- валидационную выборку;
- тестовую выборку.

Валидационная выборка использовалась для выбора архитектуры и early stopping.  
Тестовая выборка использовалась только для финальной оценки выбранной модели.

Перед передачей изображения в модель выполняется предобработка:

- приведение изображения к размеру `28 × 28`;
- преобразование изображения в tensor;
- нормализация значений пикселей.

### Модель

В качестве модели используется свёрточная нейронная сеть **CNN**.

Были проведены несколько экспериментов:

- baseline CNN;
- CNN с Dropout;
- CNN с увеличенным количеством каналов;
- CNN с дополнительным свёрточным слоем;
- CNN с weight decay.

Лучший результат показала модель с тремя свёрточными блоками.

Архитектура выбранной модели:

```text
Input: 1 × 28 × 28

Conv2d: 1 → 16
BatchNorm
ReLU
MaxPool

Conv2d: 16 → 32
BatchNorm
ReLU
MaxPool

Conv2d: 32 → 64
BatchNorm
ReLU
MaxPool

Flatten
Linear
ReLU
Linear → 47 classes
```

Основные гиперпараметры:

- количество каналов: `(16, 32, 64)`;
- размер скрытого слоя: `64`;
- optimizer: `Adam`;
- learning rate: `0.001`;
- loss function: `CrossEntropyLoss`;
- максимальное количество эпох: `30`;
- используется early stopping;
- размер входного изображения: `28 × 28`;
- количество классов: `47`.

### Результат

Лучшая архитектура выбиралась по качеству на validation dataset.

На независимой тестовой выборке модель показала:

**Accuracy: 87.47%**

> Если после изменения preprocessing или ориентации EMNIST модель была переобучена, здесь необходимо указать актуальную test accuracy последней модели.

Финальная модель сохраняется в файле:

```text
model.ckpt
```

Checkpoint содержит:

- веса модели;
- конфигурацию архитектуры;
- значение validation loss.

## 3. Установка и запуск сервиса

### Клонирование репозитория

```bash
git clone <link/to/your/repo>
cd practice-cnn
```

### Сборка Docker-образа

```bash
docker build -t emnist .
```

Точка `.` в конце команды указывает Docker использовать текущую директорию как контекст сборки.

### Запуск контейнера

```bash
docker run --rm -p 8000:8000 emnist
```

После запуска web-интерфейс будет доступен по адресу:

```text
http://localhost:8000
```

Swagger-документация FastAPI:

```text
http://localhost:8000/docs
```

## 4. Использование

После запуска приложения откройте:

```text
http://localhost:8000
```

Далее:

1. Нарисуйте один символ на canvas.
2. Нажмите кнопку `Predict`.
3. Изображение будет уменьшено до размера `28 × 28`.
4. Данные будут отправлены в FastAPI.
5. CNN выполнит классификацию.
6. Результат появится в поле `Prediction`.

Кнопка `Clear` очищает область рисования.

Модель предназначена для распознавания **одного символа за один запрос**.

Изображения с несколькими символами одновременно, например `20`, `ABC` или `123`, текущей моделью не поддерживаются.

## 5. API

### POST `/api/predict`

На вход передаётся массив из `784` значений пикселей изображения.

Полный массив соответствует изображению:

```text
28 × 28 = 784 пикселя
```

Пример ответа:

```json
{
  "prediction": "A"
}
```
